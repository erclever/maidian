# 技术说明

## 应用结构

脉点使用 Swift/AppKit 构建菜单栏应用，通过 `NSStatusItem` 显示网速，通过无边框 `NSPanel` 展示详细信息；`NSVisualEffectView` 使用系统菜单材质。`main.swift` 包含界面、采样调度、格式化及进程排行；`temperature.c` 与 `bridging.h` 实现只读 SMC 温度采样；`Info.plist` 定义应用标识、图标及最低系统版本。

程序无后台服务、数据库、账户和遥测模块。面板打开后启动系统指标和应用排行采样，关闭后停止后续详细采样；状态栏总网速继续更新。界面更新在主线程，命令采样及温度读取在后台执行。

## 数据来源和口径

| 数据 | 读取方式 | 刷新与注意事项 |
| --- | --- | --- |
| 总网速 | `getifaddrs` 中已启用 `en*` 接口的累计字节数 | 每 2 秒按实际时间差计算；新接口、计数回退或较长间隔不产生虚假增量；不计 `utun`。这不是专门的互联网流量统计。 |
| 网络排行 | `/usr/bin/nettop -n -P -L 1 -J bytes_in,bytes_out -x` | 打开面板并选择网络时采样；两次进程累计计数差计算速率，按总速、下载或上传排序。进程生命周期、权限及接口范围可能导致与总网速不一致。 |
| 内存排行 | `/bin/ps -axo pid=,rss=,comm=` | 打开面板并选择内存时读取，以进程 RSS 汇总；共享页可能被重复计数，不能作为精确物理内存分摊。 |
| 应用归属 | `proc_pidpath`、最外层 `.app` 的 bundle ID 与 `NSRunningApplication` | 可以识别时合并辅助进程；不能识别时保留进程名称。只显示前 10 项。 |
| CPU | `host_statistics(HOST_CPU_LOAD_INFO)` | 基于两次 CPU tick 差计算整体使用率。 |
| 系统内存 | `host_statistics64(HOST_VM_INFO64)`、`vm.swapusage` | 活跃、非活跃、有线及压缩页面减去部分可回收页面的估算；展示总量、压缩和交换使用。不是 Apple 活动监视器的保证一致口径。 |
| 磁盘 | `FileManager.attributesOfFileSystem(forPath: "/")` | 每 30 秒读取 `/` 所在文件系统；进度条表示估算已用比例。 |
| CPU 温度 | IOKit `AppleSMC` 只读调用，固定 `Tp*` / `Te*` 键 | 每 5 秒读取有效 `flt` 值，取合理范围内的平均值；非公开接口，失败显示不可用。蓝色 <60°C、橙色 60–<80°C、红色 ≥80°C；阈值是界面区分，不构成硬件健康结论。 |

## 生命周期与错误处理

`SamplingCommandRunner` 对 `ps` 和 `nettop` 设置 5 秒超时，通过代际标识拒绝过期任务。关闭面板、切换排行或正常退出会终止当前子进程；失败时显示重试状态，不将采样失败表述为零流量。网络首次计算需要两次有效样本。面板关闭时没有详细数据的周期性采集，但一次已开始的温度读取可能短暂完成。

状态栏按钮和面板的定位、按 Esc 或点击外部关闭依赖 macOS 窗口和事件机制；多显示器、权限策略和不同系统版本仍需实机验证。系统登录项使用 `SMAppService.mainApp`，无需手写 LaunchAgent。

## 资源与隐私边界

网络与进程统计来自本机系统接口，源码中没有上传、账号、第三方分析或历史持久化功能。进程名称、图标和资源数值可在面板显示；不要将包含个人应用名称、路径或状态的截图、日志、测试输出直接公开。图标位于 `assets/AppIcon.icns`，生成源为 `assets/draw-icon.swift`。
