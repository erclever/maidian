# 隐私与安全

脉点在本机读取系统资源数据、网络接口字节计数、进程名与进程占用信息，用于当前面板和菜单栏显示。源码没有账户、遥测或将这些指标上传到远端的功能，也不保存历史流量数据库。登录启动仅在用户通过面板开关操作时向系统注册或取消注册。

排行使用系统 `ps` 和 `nettop`；权限、系统版本或进程退出可能影响结果。CPU 温度读取非公开 SMC 接口，失败时显示不可用。工具不请求管理员权限，但这不代表所有 macOS 环境都能读取相同数据。

开发诊断可能在 `build/` 生成截图或临时文件，其中可能出现本机进程名称及使用状态。该目录被 Git 忽略，不应随代码发布。对外分享截图、日志或运行记录前应检查其中的个人信息。

仓库源码可供审查；本地 ad hoc 签名不等同于开发者身份验证或 Apple 公证。下载的构建物是否可信，应由接收者自行核验来源和完整性；不要要求用户关闭系统安全保护。
